# 本地提示「信号隧道」— 实施计划（本期）

> 本期**只做本地自用的提示功能**，不碰 UDP / 团队广播（那套引擎将来复用，本期不实现）。
> 目标：让你不用再时不时切终端去查「agent 跑完没 / 卡住没 / 挂没挂」——余光扫一眼监视器底部的「信号隧道」就知道，亮了才动手。

---

## 1. 一句话目标

在现有额度监视器**下方挂一条横向「信号隧道」**：每个需要你注意的会话 = 一格彩色 chip（带项目名）。
- 🟢 完成（信息）→ hover 到那格、停一下就消
- 🟡 卡住等你批准/输入（待办）→ 你真去处理才消
- 🔴 出错/限流（待办）→ 你真去处理才消
- 正常在跑 / 空闲 → 不占格子（隧道为空时整条收起，窗口保持紧凑）

---

## 2. 信号隧道 UI（依据你画的图）

```
┌──────────────────────────┐
│        现有额度界面        │   ← 保持不动（Claude/Codex 额度卡）
│   99% ... 今日 $... ...    │
├──────────────────────────┤
│ 🟡llm.. 🔴pay.. 🟢web.. ›3│   ← 信号隧道：横向 chip 传送带
└──────────────────────────┘
        ← 向左流，左边空了右边补上来；右侧放不下的裁掉，用 ›N 标还有几个
```

**布局与流动：**
- 隧道是现有窗口**底部挂的一条**，**有 chip 才出现**、空了就收起（窗口随之变矮，平时紧凑）。
- chip 横向排列，**左对齐**；放不下的在**右侧裁掉**，右端用 `›N` 标「还有 N 个被裁掉」。
- 清掉/消失一格 → 右边的**向左滑动补位**（平滑动画，隧道流动感）。
- 每格 chip = `[工具图标] 项目名`，**边框颜色=状态**（绿/黄/红），名字过长截断（`LLMMonitor`→`llm…`），hover 时显示完整名 + 详情 tooltip。

**排序（在你图基础上加的一个安全改进）：**
- 🔴🟡（必须你动手的）**靠左固定、永不被裁掉**；🟢（纯信息）排在其后、可被右侧裁掉。
- 原因：绿的只是「知道一下」，被裁无所谓；但红/黄要是被一堆绿挤到右边裁掉、你就漏了该干的活。所以让「待办」始终可见。
- 同优先级内按发生时间排（新的靠右）。

**交互：**
- 🟢 绿格：**hover 停约 0.3 秒 → 淡出消失**（精确清你光标停的那一个；停顿防止鼠标路过误清）。一次清一个，你都过眼。
- 🟡🔴 黄/红格：**hover 不清**（只显示详情）；只有你**真去处理了**（见第 4 节）才消。
- 全程**不点击、不跳转**（按你定的，本期都不做）。

## 3. 数据与信号来源（已在你机器上验证）

纯本地读 CLI 自己写的会话日志，不监听键盘/屏幕/窗口：
- Claude：`~/.claude/projects/<编码cwd>/<session>.jsonl`，文件夹名=项目名。
- Codex：`~/.codex/sessions/年/月/日/rollout-*.jsonl`，`cwd` 字段=项目。

**判定每个会话的状态（实测信号）：**

| 状态 | chip | 信号（日志里读得到） |
|---|---|---|
| 🟢 完成 | 绿 | 最新 assistant 消息 `stop_reason = end_turn`（或 `stop_sequence`），其后无新的 user 消息，且未被你清过 |
| 🟡 等你 | 黄 | 最新 assistant 是 `tool_use`，但**超过阈值（默认 ~45s，可调）没有后续 tool_result/user** → 卡在等批准/输入 |
| 🔴 出错 | 红 | 出现 `isApiErrorMessage:true` 或 `subtype:"api_error"`（会话级断了/限流） |
| 在跑 | 无 | 最近几秒有新活动 / `tool_use` 正常推进（有后续）→ 不出 chip |
| 空闲 | 无 | 一段时间无任何活动 |

> 注意：工具调用失败的 `is_error:true`（很常见，agent 自己会消化）**不算红灯**，只有会话级 `api_error`/`isApiErrorMessage` 才算。

**归属**：每个 chip 标明工具（claude/codex）+ 项目名（取该会话日志所属文件夹 / cwd）。

## 4. 灭灯（清除）规则 —— 统一规则

一条规则管所有颜色，**完全由 jsonl 文本变化驱动**：

```
chip 显示  ⟺  会话「最新有意义条目」∈ {assistant end_turn(绿) / 卡住的 tool_use(黄) / api_error(红)}
                且 该触发条目比你对此会话的「dismiss 标记」新

自动消（任意颜色）：日志又追加了新条目（最新条目不再是触发事件）
  → 绿: llm 又继续跑了 / 黄: 批准·输入到了 / 红: 重试·恢复了 —— 都是"追加了新条目"
手动消（任意颜色）：hover 到该格停 ~0.3s → 把 dismiss 标记设到当前触发条目
```

要点：
- chip 是**会话状态的纯投影** = f(日志最新条目, 该会话的 dismiss 标记)，无别的判断、几乎无额外状态。
- **所有颜色 hover 都能消**（统一），不再区分"绿能清黄红不能"。
- hover 消掉一个**仍未解决**的黄/红后：**不再冒**，直到该会话日志又有**新条目**才重新评估（=出现比 dismiss 标记更新的触发事件）。刚发生时的 toast 已进 Windows 通知中心兜底，不会真丢。
- 30 分钟超时**降级为可选兜底**（hover 已能手动清任意一个）。

---

## 5. 主动通知（toast）

- 某会话**刚切换**到 🟢/🟡/🔴 的那一下，弹一个 Windows 通知（带工具+项目名，如「✅ Claude·LLMMonitor 完成」「⏸ Codex·payment 等你批准」「⚠️ Claude·LLMMonitor 出错/限流」）。
- toast 进 Windows 通知中心**留存**，是「人不在场也不漏」的真正兜底；隧道 chip 则是「在场时一眼可见」的环境指示。
- 可配置：每种颜色是否弹 toast（默认绿可选、黄/红默认弹）、是否带提示音。

---

## 6. 检测机制（要快）

- 用 `notify` 文件监听盯住 `~/.claude/projects`、`~/.codex/sessions` 的变化 → **秒级**更新隧道 + 弹 toast。
- 另加一个低频兜底全量复核（如每 30s），处理监听漏掉的情况、跑超时判定（黄灯卡住阈值、30 分钟兜底）。

---

## 7. 架构 / 模块（在现有 exe 内扩展，不另起程序）

**Rust 新增/改动：**
- `activity.rs`（核心引擎，新）：扫描+监听会话日志 → 维护「每会话状态表」`{tool, project, state, sinceTs, lastMsgId, acked}` → 算出当前 chip 列表 → 状态突变时发通知。复用 `usage.rs` 的 jsonl 读取 / 项目名解码逻辑。
- 监听：引入 `notify` crate；`collector.rs` 旁挂一个 watcher 线程。
- 通知：引入 `tauri-plugin-notification`。
- `state.rs`：`AppState` 增加 `chips: Vec<Chip>` 字段，随事件 emit 给前端。
- 命令：`ack_chip(id)`（前端 hover 清绿时调用，把该绿标记已确认）。

**前端（现有窗口内）：**
- 现有额度卡**不动**；底部新增「信号隧道」组件。
- 渲染 chip 列表（颜色/图标/截断名）、左流补位动画、右侧裁剪 + `›N`、🟢 hover-0.3s 清除、🟡🔴 仅显示 tooltip。
- 隧道空 → 收起，窗口高度回到现状。

**配置 `config.json`（新）：** 黄灯卡住阈值、绿灯超时(默认30min)、各色 toast 开关、提示音开关。

## 8. 分阶段实施

| 阶段 | 内容 | 产出/验证 |
|---|---|---|
| 1 | `activity.rs`：从日志判定每会话 state（end_turn/卡住/api_error） | 命令行 dump 当前 chip 列表，肉眼核对 |
| 2 | `notify` 监听 + 30s 兜底复核 | 改动会话后秒级反映 |
| 3 | 清除状态机（绿 ack / 黄红动手即灭 / 超时 / 不复亮） | 各路径逐一验证 |
| 4 | 前端信号隧道 UI（流动/裁剪/hover清绿） | 视觉与交互成形 |
| 5 | toast 通知 + 配置项 | 切换时弹窗、可调 |
| 6 | 打磨 + 重打 release 安装包 | 可分发 |

## 9. 隐私

全程只读 CLI 已经在写的 JSONL 日志；**不监听键盘、不截屏、不监控窗口焦点**。所有判断（完成/卡住/出错/你是否处理）都来自日志内容，天然带会话归属。

## 11. 待定 / 可调（默认值，回头都能改）

- 黄灯「卡住」阈值：默认 ~45 秒无后续。
- 绿灯超时兜底：默认 30 分钟。
- 隧道一屏显示几格 / chip 宽度：实现时按窗口宽度定，溢出 `›N`。
- 各色 toast 开关、提示音：默认绿不弹/黄红弹、无声。
